# GitHub Specialist Agent

Sistema foi desenvolvido para facilitar a criação e controle dos repositórios do Github. Pensado principalmente nos devs mais jovens que ainda podem ter alguma dificuldade em organizar seu Github.
O sistema foi criado para ser leve e rápido e de fácil entendimento de todos.

## 🚀 Tecnologias e Frameworks

- **Linguagem:** JavaScript vanila ES6+, Html5 e CSS3
- **Frameworks:** Tailwind CSS, Marked.js, FontAwesome

## 🛠️ Como Executar o Projeto

```bash
Instalação simples, que o Dev só precisa baixar os arquivos numa pasta zipada e depois fazer a extração. Abrir o Index.html ou agente.html, colocar sua PAT do Github e começar a usar. Vantagem que as informações ficam salvas localmente, e não corre o risco de enviar seus dados para terceiros caso você compartilhe esse agente.
```
