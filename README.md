# Agente Especialista em GitHub (Com GitHub Pages Automático)

Esta versão atualizada inclui a **automação total do GitHub Pages** diretamente pela API do GitHub.

## 🚀 Novidades desta Versão

1. **Aba "Ativar GitHub Pages"**: Permite ativar e publicar qualquer repositório como um site ou app web com 1 clique.
2. **Criação com Auto-Pages**: Na aba de criação de repositório, você pode marcar a caixinha "Ativar GitHub Pages automaticamente após a criação".
3. **Verificação de Status & Link**: Exibe o link direto do seu site publicado (ex: `https://seu-usuario.github.io/seu-repo/`).

---

## 📲 Como Usar no Computador

1. Baixe o arquivo `Agente-GitHub-Pages-Completo.zip`.
2. Transfira para o seu PC via cabo USB ou e-mail/WhatsApp.
3. Extraia o ZIP e abra o `index.html`.
4. Insira seu Token do GitHub e aproveite a publicação automática de sites no GitHub Pages!
