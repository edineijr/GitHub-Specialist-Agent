Comandos Git / VS Code

Copie os comandos exatos para inicializar ou atualizar este repositório via terminal do VS Code.

1. Primeiro Envio (Repositório Novo) 
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin main
2. Atualizar Código Existente (Commit & Push) 
git add .
git commit -m "update: atualiza fontes do projeto"
git push origin main
